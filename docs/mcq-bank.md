# MCQ প্রশ্নব্যাংক

ভবিষ্যতের লাইভ MCQ পরীক্ষার জন্য প্রশ্ন **বিষয় ও অধ্যায় আলাদা করে** রাখা হয়। এখনো সাইটে কোনো পরীক্ষার পেজ নেই।

## কোথায় কী থাকে

| জায়গা | কাজ |
|---|---|
| Google Sheet — `প্রশ্ন` ট্যাব | প্রশ্ন লেখা, সংশোধন ও শিক্ষকের যাচাই। প্রতিটি সারি একটি প্রশ্ন। |
| Google Sheet — `অধ্যায় তালিকা` ট্যাব | অধ্যায়ের ড্রপডাউনের উৎস (সাইটের ট্র্যাকারের ২৮৬টি অধ্যায়)। হাতে বদলাবে না। |
| Supabase `mcq_subjects`, `mcq_chapters` | ১৬টি বিষয় ও ২৮৬টি অধ্যায়, `site/tracker.html` থেকে তৈরি। |
| Supabase `mcq_questions` | সব প্রশ্ন। সাইটের দর্শক কেবল `verified` প্রশ্ন দেখতে পায়, তাও শুধু প্রশ্ন, অপশন, উত্তর, ব্যাখ্যা ও কঠিনতা। খসড়া, বাতিল, যাচাইকারীর নাম ও উৎস গোপন থাকে। |
| `data/mcq/*.json` | প্রথম খসড়া ব্যাচগুলোর মূল কপি। |
| `scripts/mcq.cjs` | যাচাই ও SQL তৈরির টুল। |

প্রশ্নের কোড `বিষয়-অধ্যায়-ক্রম`, যেমন `physics-012-003` মানে পদার্থবিজ্ঞানের `data-chapter="12"` অধ্যায়ের ৩ নম্বর প্রশ্ন। অধ্যায় নম্বর সাইটের ট্র্যাকারের `data-chapter` এর সাথে মেলে।

## খসড়া সম্পর্কে সতর্কতা

AI ব্যাচ ১-এর ২৮৫টি প্রশ্ন (ICT, পৌরনীতি, পদার্থবিজ্ঞান, রসায়ন — প্রতি অধ্যায়ে ৫টি) মৌলিকভাবে লেখা **অযাচাইকৃত খসড়া**। কোনো ওয়েবসাইট বা বই থেকে কপি করা হয়নি। এগুলোর অবস্থা `খসড়া`; শিক্ষক যাচাই না করা পর্যন্ত সাইটে দেখা যাবে না। বোর্ড প্রশ্ন যোগ করলে উৎস `বোর্ড প্রশ্ন` দিয়ে বোর্ড ও সাল উৎসের নোটে লিখতে হবে; অন্য সাইটের প্রশ্নব্যাংক কপি করা যাবে না।

## শিক্ষকের যাচাই

1. `প্রশ্ন` ট্যাবে প্রশ্ন, চারটি অপশন, `সঠিক উত্তর` (ক/খ/গ/ঘ) ও ব্যাখ্যা মিলিয়ে দেখুন; ভুল থাকলে ঠিক করুন।
2. ঠিক থাকলে `অবস্থা` = **যাচাই হয়েছে**, `যাচাইকারী` = নিজের নাম, `যাচাইয়ের তারিখ` = বছর-মাস-দিন (যেমন `2026-11-20` বা `২০২৬-১১-২০`)।
3. ব্যবহারযোগ্য না হলে `অবস্থা` = **বাতিল**।
4. নতুন প্রশ্ন: নিচে নতুন সারিতে `কোড` ফাঁকা রেখে অধ্যায় ড্রপডাউন থেকে বেছে নিন, উৎস `শিক্ষক`। কোড পরে স্বয়ংক্রিয়ভাবে দেওয়া হবে।

হেডার সারি, কলামের ক্রম ও `অধ্যায় তালিকা` ট্যাব বদলাবেন না; বদলালে টুল সিঙ্ক বন্ধ করে দেবে।

## Sheet থেকে Supabase-এ সিঙ্ক

1. Sheet-এ `প্রশ্ন` ট্যাব খোলা রেখে **File → Download → Comma-separated values (.csv)**।
2. রিপোজিটরিতে চালান:

   ```sh
   node scripts/mcq.cjs sheet-csv path/to/downloaded.csv > mcq-sync.sql
   ```

   কোনো সারিতে সমস্যা থাকলে (অধ্যায় বাছা হয়নি, অপশন একই, উত্তর ফাঁকা, যাচাই হয়েছে কিন্তু নাম/তারিখ নেই, একই প্রশ্ন দুবার) সারি নম্বরসহ ভুল দেখিয়ে থেমে যাবে; Sheet ঠিক করে আবার চালান।
3. তৈরি `mcq-sync.sql` Supabase SQL Editor-এ (প্রকল্পের মালিক বা service role হিসেবে) চালান। Sheet-ই মূল কপি, তাই একই কোডের সারি Sheet-এর লেখা দিয়ে হালনাগাদ হয়।
4. টুল টার্মিনালে `Write these codes back to the Sheet` দেখালে সেই সারিগুলোর `কোড` ঘরে দেখানো কোড লিখে দিন, যাতে পরের সিঙ্কে একই প্রশ্ন নতুন কোড না পায়।

Sheet থেকে সারি মুছলে Supabase থেকে মোছে না; প্রশ্ন সরাতে `অবস্থা` = `বাতিল` দিন।

## নতুন খসড়া ব্যাচ

নতুন JSON `data/mcq/`-এ রেখে:

```sh
node scripts/mcq.cjs check                  # অধ্যায় মিলছে কি না, ডুপ্লিকেট, উত্তরের অবস্থান
node scripts/mcq.cjs sql-questions 60       # ৬০ সারির খণ্ডে SQL (`-- CHUNK --` দিয়ে আলাদা)
node scripts/mcq.cjs sheet-rows             # Sheet-এ বসানোর সারি (JSON)
```

খসড়া SQL `ON CONFLICT (code) DO NOTHING` ব্যবহার করে, তাই আবার চালালেও যাচাই করা প্রশ্ন বদলাবে না। অপশনের ক্রম কোড থেকে নির্দিষ্টভাবে এলোমেলো হয়, ফলে সঠিক উত্তর সব সময় একই অক্ষরে পড়ে না।

ট্র্যাকারে অধ্যায় যোগ বা বদল হলে `node scripts/mcq.cjs sql-chapters` চালিয়ে অধ্যায় টেবিল হালনাগাদ করুন এবং Sheet-এর `অধ্যায় তালিকা` নতুন করে বসান।

## পরের ধাপ

- বাকি ১২টি বিষয়ের খসড়া: উচ্চতর গণিত, জীববিজ্ঞান, বাংলা ১ম ও ২য় পত্র, English 1st Paper, সমাজবিজ্ঞান, অর্থনীতি, ইতিহাস, হিসাববিজ্ঞান, ব্যবসায় সংগঠন ও ব্যবস্থাপনা, ফিন্যান্স ব্যাংকিং ও বিমা, উৎপাদন ব্যবস্থাপনা ও বিপণন।
- যথেষ্ট প্রশ্ন যাচাই হলে সাইটে লাইভ পরীক্ষার পেজ, যা Supabase-এর anon key দিয়ে কেবল `verified` প্রশ্ন পড়বে।
