প্রকাশ্য তথ্য: GitHub Issue সবাই দেখতে পারে। ফোন নম্বর, রোল নম্বর, পাসওয়ার্ড বা অন্য ব্যক্তিগত তথ্য লিখো না। নিরাপত্তার দুর্বলতা থাকলে নিচের গোপন রিপোর্টের পথ ব্যবহার করো।

সর্বোচ্চ ৫০০ অক্ষর। সংবেদনশীল বা ব্যক্তিগত তথ্য দিও না।

আরও তথ্য (ঐচ্ছিক)

শুধু ফর্ম পূরণ করলে Issue তৈরি হয় না। GitHub অ্যাকাউন্টে লগইন করে সেখানে Submit new issue চাপার পর প্রকাশিত হবে; ইন্টারনেট প্রয়োজন।

আগের মতামত ও Issue দেখো ↗প্রকাশের পর একই Issue-তে অগ্রগতি দেখা যাবে।
